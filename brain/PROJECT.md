# Project Blueprint — SENTINEL

## System Purpose
Specialized operational intelligence and campus facilities workstation for facility operators, building automation engineers, and institutional leaders.

## Core Operations Loop
1. **OBSERVE**: Unified digital twin map, building cards, live telemetry streams.
2. **INVESTIGATE**: Deep root cause diagnosis with baseline comparisons, environmental and schedule context matrix, contributing sensor signals.
3. **UNDERSTAND**: Corroborate mechanical faults (e.g. stuck reheat valve actuator) without hallucination. Quantify energy, financial ($52.40/day), and carbon penalties.
4. **ACT**: Dispatch structured work orders through formal 5-stage lifecycle (`Open` → `Assigned` → `In Progress` → `Resolved` → `Verified`).
5. **VERIFY**: Real-time sensor feedback confirms draw drops to 0.98 kW baseline and clears anomaly.
